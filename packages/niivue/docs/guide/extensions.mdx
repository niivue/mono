The core `@niivue/niivue` package views images. Heavier jobs, such as
converting DICOM or running image filters, live in separate packages, so
you only ship what you use. Most of them do their work in a Web Worker, so
the page stays responsive while they compute.

## DICOM: dcm2niix

```bash
npm install @niivue/dcm2niix
```

NiiVue does not read DICOM directly. `@niivue/dcm2niix` runs dcm2niix
(compiled to WebAssembly) in the browser and returns NIfTI series you can
load:

```js
import { convert } from '@niivue/dcm2niix'

// <input id="dicomFolder" type="file" webkitdirectory multiple />
input.addEventListener('change', async () => {
  // A nonzero exit still returns the series that converted.
  const { series } = await convert(input.files)
  await nv.loadVolumes([{ url: series[0].image }])
})
```

Each series also carries its `json` sidecar and any `bval`/`bvec`. For a
dropped folder, `filesFromDataTransfer(e.dataTransfer.items)` collects the
files first; `listSeries` lists series without converting them. The
`Dcm2niix` class gives full control over the dcm2niix flags:

```js
import { Dcm2niix } from '@niivue/dcm2niix'

const dcm2niix = new Dcm2niix()
await dcm2niix.init()
const result = await dcm2niix.input(files).compressionLevel(9).bids('n').run()
```

[Live demo](https://niivue.github.io/mono/demo-ext-dcm2niix/)

## The extension packages

Each package has its own page with install steps and examples:

- [Slides and OME-Zarr](/packages/nv-ext-tile/) (`@niivue/nv-ext-tile`):
  open whole-slide images (pyramidal TIFF, SVS, DICOM-WSI) and OME-Zarr
  volumes, loading only the parts in view.
- [Image filters](/packages/nv-ext-niimath/) (`@niivue/nv-ext-niimath`):
  smooth, threshold, mask and more with niimath, an fslmaths clone.
- [Image processing](/packages/nv-ext-image-processing/)
  (`@niivue/nv-ext-image-processing`): Otsu thresholding, haze removal and
  other volume transforms.
- [Drawing tools](/packages/nv-ext-drawing/) (`@niivue/nv-ext-drawing`):
  fill the slices between two drawn ones, and a 3D magic wand.
- [Isosurfaces](/packages/nv-ext-isosurface/) (`@niivue/nv-ext-isosurface`):
  surface meshes from streamed volumes.
- [HTML export](/packages/nv-ext-save-html/) (`@niivue/nv-ext-save-html`):
  save the current scene as one HTML file that opens without a server.
