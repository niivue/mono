---
title: React
description: "Use NiiVue in a React 19 app with the @niivue/nvreact package."
---

The `@niivue/nvreact` package puts NiiVue viewers in a React 19 app. It
handles the canvas, resizing and cleanup, so a viewer is one component:

```tsx
import { NvViewer } from '@niivue/nvreact'

export function Brain() {
  return (
    <NvViewer
      volumes={[{ url: '/volumes/mni152.nii.gz' }]}
      style={{ height: 500 }}
    />
  )
}
```

For a grid of linked viewers, and for reaching the NiiVue instance behind
each one, see the [React package docs](/packages/nv-react/).

To use NiiVue in React without the package, see the React tab under
[A first viewer](/guide/#a-first-viewer).
